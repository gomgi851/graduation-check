# 졸업 체크

공통교양·일반교양·MSC·전공의 필요 학점과 과목별 이수 기록을 관리하는 정적 웹 앱입니다.

## 기능

- 분류별 색상 배지와 행 표시로 전공·공통교양·일반교양·MSC 구분

- 4.5 만점 전체·전공 평점: 학점 가중평균, F 0점 포함 및 P·NP 제외

- 총 졸업 요구 학점 및 분류별 기준 설정, 취득·부족 학점 비교
- 과목명, 분류, 학점, 성적, 수강 학년(1~6학년)·학기(1·2학기) 입력
- 학년마다 1·2학기를 나란히 배치, 기본 1~4학년 표시
- 과목 수정·삭제, 분류 필터
- 학년·학기 정보가 없는 이전 기록은 학기 미지정으로 보존
- 브라우저 localStorage 저장 및 JSON 내보내기·불러오기
- A0 등 0 표기 미사용, F·NP는 취득 학점에서 제외

## 실행

의존성 설치나 빌드가 필요 없습니다.

```sh
python3 -m http.server 4173 --directory dist
```

브라우저에서 http://localhost:4173 을 엽니다.

## 검증

```sh
node --check dist/app.js
node --test tests/records.test.cjs
```

기록은 해당 브라우저에만 저장됩니다. 저장소에는 개인 수강 기록이 포함되지 않습니다.
필수 과목, 재수강, 중복 인정 등 학교별 세부 규정은 자동 판정하지 않습니다.

## 배포

`dist/`를 정적 웹 호스팅에 배포합니다. `.openai/hosting.json`은 기존 Sites 배포 설정입니다.

## 글꼴

네이버 공식 배포 나눔스퀘어 네오 가변 웹폰트를 `dist/fonts/`에 포함합니다. 출처 및 사용 안내는 해당 폴더의 README.txt를 참고하세요.
